usage

Drop-in tokens

Reference the CSS custom properties directly — no build step, no framework.

app.css 
/* every surface and accent from one file */
.cta {
  background: var(--c-gold);
  color:      var(--c-black);
}
.panel {
  background: var(--c-sable);
  border:     var(--border);
  color:      var(--c-text);
}
PS> build-theme.ps1 
# generate the ramp from the PowerShell blue
Get-Palette -BaseHex '#012456' -Accent '#E3B341' `
  | Export-Theme -As Css -Path './poshakuchadark.css'
